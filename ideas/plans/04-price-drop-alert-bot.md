# 04. 가격 하락 알림 봇 + 제휴 수수료

## 최종 목표
- **6개월 안에 활성 사용자 300명, 월 제휴 수익 10만 원 이상**
- 가격 확인·알림·제휴 링크 변환까지 100% 자동, 운영은 **주 1시간 이하**
- 본인 구매에서 연 10만 원 이상 절약 (봇이 실패해도 남는 최소 효과)

## MVP 범위
- 텔레그램 봇 1개 (앱 설치 없이 바로 쓸 수 있고 봇 API가 무료)
- 명령: `/add 검색어 목표가`, `/list`, `/del 번호`
- 하루 4회 가격 확인, 목표가 이하 또는 30일 최저가 갱신 시 알림
- 알림 메시지에 제휴 링크 + 제휴 고지 문구

## 기술 구조
- 가격 소스: 네이버 쇼핑 검색 API (developers.naver.com, 무료, 일일 호출 한도 있음)로 최저가 추적
  - 쿠팡 상품은 쿠팡 파트너스 API를 쓰되, **API 사용 승인 조건을 먼저 확인** (페이지 스크래핑은 약관 위반이므로 금지)
- 봇: Python + python-telegram-bot
- 스케줄러·DB: 작은 VPS 1대 또는 Cloudflare Workers 크론 + Supabase 무료 티어 (사용자·상품·가격 이력)
- 비용: 초기 월 0~5천 원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 계정 준비 | 네이버 개발자 앱 등록(쇼핑 검색 API), 쿠팡 파트너스 가입·API 조건 확인, 텔레그램 BotFather로 봇 생성 | 키 3종 확보, 각 서비스 약관의 자동화·고지 조항 메모 |
| 1. 가격 수집기 | 검색어 → 상품 후보 → 최저가 조회, 옵션·묶음 상품 오매칭 필터 | 내 관심 상품 10개의 가격을 7일간 기록 |
| 2. 알림 로직 | 목표가 도달, 30일 최저가, 전일 대비 N% 하락 3가지 조건 + 같은 알림 반복 방지 | 테스트 데이터로 3가지 조건 모두 정상 발송 |
| 3. 텔레그램 봇 | 등록·조회·삭제 명령, 사용자별 상품 목록 | 본인이 2주간 실사용 |
| 4. 제휴 링크 | 알림 링크를 제휴 링크로 변환, 메시지에 "제휴 수수료를 받을 수 있습니다" 고지 | 클릭·주문이 제휴 대시보드에 집계 |
| 5. 지인 베타 | 지인 10~20명 초대, 피드백으로 오매칭·알림 빈도 조정 | 주간 활성 사용자 10명 |
| 6. 가격 이력 웹페이지 | 상품별 가격 그래프 공개 페이지 (검색 유입 + 봇 가입 유도) | 페이지에서 봇 가입 전환 발생 |
| 7. 성장 | 시즌 이벤트(블랙프라이데이 등) 전 커뮤니티 규칙을 지키며 소개, 인기 상품 자동 추천 | 활성 사용자 300명 |

## 법·정책 주의사항
- 공정위 「추천·보증 등에 관한 표시·광고 심사지침」: 제휴 링크임을 메시지에 명확히 표시
- 각 쇼핑·제휴 서비스 약관의 API 사용 범위, 호출 한도, 링크 사용 방식 준수
- 사용자 정보는 텔레그램 ID와 등록 상품만 저장 (개인정보 최소 수집)

## 리스크와 대응
- 상품 오매칭(옵션·용량 차이) → 사용자가 후보 중 직접 선택하게 하는 UI
- API 한도 초과 → 같은 상품은 사용자 수와 무관하게 1회만 조회 (캐시)
- 제휴 정책 변경 → 링크 변환을 모듈로 분리해 다른 제휴처로 교체 가능하게
