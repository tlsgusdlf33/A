# 20. 정부 창업·지원사업 자동 매칭 알림

## 최종 목표
- **나에게 해당하는 지원사업 공고를 놓치는 일 0건**
- 12개월 동안 3건 이상 지원, 1건 이상 선정 → 지원금으로 채택 프로젝트(1·4·10·16번 등)의 개발·운영 비용 충당
- 공고 확인은 **주 10분 이하**, 지원할 공고는 마감 14일 전에 결정

## MVP 범위
- 공공 API로 지원사업 공고 매일 수집
- 내 프로필과 자격 조건 매칭 → "지원 가능 / 확인 필요 / 불가" 3단계 판정
- 새 매칭 공고 즉시 알림 + 마감 D-14·D-3 알림 + 제출 서류 체크리스트

## 기술 구조
- 데이터 (공식 API 우선):
  - 기업마당(bizinfo.go.kr) 지원사업 정보 API
  - 창업진흥원 K-Startup 사업공고 정보 (공공데이터포털)
  - 각 API의 제공 필드·갱신 주기·이용 조건을 0단계에서 확인
- 자격 조건 해석: 공고 본문·첨부 공고문의 자격 요건을 LLM으로 구조화 (나이, 예비창업자/업력, 지역, 업종, 재직자 신청 가능 여부, 사업자 필요 여부, 중복 수혜 제한)
- 내 프로필: 설정 파일 1개 (나이, 재직 여부, 사업자 유무·업력, 지역, 관심 분야, 진행 중인 프로젝트 목록)
- 저장: SQLite (공고, 판정, 근거 문장, 지원 이력)
- 알림: 텔레그램
- 비용: 거의 0원 (LLM 호출은 새 공고에만)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. API 확보 | 기업마당·K-Startup API 키 신청, 응답 필드와 첨부 공고문 형식(HWP·PDF) 확인 | 샘플 공고 20건 저장 |
| 1. 수집기 | 매일 신규·변경 공고 수집, 중복 제거, 마감 지난 공고 정리 | 7일 연속 수집 성공 |
| 2. 내 프로필 | 자격 판정에 필요한 항목을 설정 파일로 정리, **회사 취업규칙의 겸업 규정 확인 결과도 기록** | 프로필 파일 완성 |
| 3. 자격 구조화·판정 | 공고별 자격 요건 추출 → 3단계 판정, 판정 근거 문장 함께 저장 | 공고 30건 판정을 직접 검수해서 90% 이상 일치 |
| 4. 알림 | 새 "지원 가능" 공고 즉시, 마감 D-14·D-3, 제출 서류·양식 다운로드 링크 | 2주 실사용, 불필요한 알림 최소 |
| 5. 사업계획서 준비 도우미 | 공고의 평가 항목과 내 프로젝트 계획 문서(`ideas/plans/`)를 연결해 목차·근거 자료 정리 (본문은 본인이 작성) | 첫 지원서 초안 준비 시간 절반으로 |
| 6. 지원 이력 관리 | 지원·발표·선정 결과·피드백 기록, 탈락 사유 정리 | 다음 지원에 피드백 반영 |
| 7. 확장 | 공모전·해커톤·지자체 지원사업 소스 추가 (공식 제공 경로만) | 연 3건 이상 지원 |

## 법·정책 주의사항
- **직장인 겸업**: 회사 취업규칙의 겸업 금지·신고 조항을 먼저 확인
- 지원사업마다 재직자 신청 가능 여부, 사업자 요건, 중복 수혜 제한이 다르므로 판정은 참고용이고 **최종 확인은 공고문 원문**
- 사업계획서는 사실에 근거해 본인이 작성: 허위 기재는 선정 취소·환수 사유
- 공공 API 이용 조건과 출처 표시 준수

## 리스크와 대응
- 공고문이 HWP 첨부로만 있는 경우 → HWP 텍스트 추출 도구 사용, 실패 시 원문 링크와 함께 "확인 필요"
- 자격 오판 → 판정 근거 문장을 알림에 같이 보여줘서 바로 검증 가능하게
- 알림 과다 → 관심 분야 가중치와 최소 지원금 규모 필터
