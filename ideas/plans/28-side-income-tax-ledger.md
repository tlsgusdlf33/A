# 28. 부업 수익 종합소득세 자동 장부

## 최종 목표
- **5월 종합소득세 신고 준비 시간 2시간 이내** (자료는 1년 내내 자동 누적)
- 수입 누락 0건, 경비 증빙 누락 0건, 해외 수입의 원화 환산 근거 100% 보관
- 연중 "예상 세금·건강보험료" 추정을 실제와 오차 10% 이내로 → 연말·5월에 놀라지 않기
- 세법·소득 구분 기준은 첫해 세무 상담으로 확정하고 설정 파일로 관리

## MVP 범위
- 수익원 3곳 이상의 수입 자동 집계 (26번 대시보드 데이터 재사용)
- 해외 수입 환율 환산, 프로젝트 경비 태그, 월별 장부 파일
- 5월 신고용 요약(수입 합계·경비 합계·증빙 목록) 생성

## 기술 구조
- 수입 데이터: 26번 대시보드의 프로젝트별 수익 (애드센스, 판매 플랫폼, PG, 스톡 로열티, API 마켓) + 은행 입금 내역(실제 원화 입금액, CSV)
- 환율: 한국은행 경제통계시스템(ECOS) Open API로 일별 환율 저장
  - **어떤 환율을 적용할지(수령일 기준, 실제 환전액 등)는 세무 상담으로 정해 설정 파일에 기록**
- 경비: 6번 카드 데이터에서 가맹점 → 프로젝트 태그 규칙 (도메인, 호스팅, LLM API, 유료 도구), 해외 서비스 인보이스는 메일 라벨로 PDF 자동 수집
- 장부: 간편장부 형식(일자, 거래 내용, 거래처, 수입, 비용, 증빙 종류)으로 월별 생성
- 설정 파일(연도별): 소득 구분, 적용 환율 기준, 경비 인정 범위, 건강보험료 기준 등
- 실행: 로컬 또는 비공개 저장소, 월 1회 자동 + 텔레그램 요약
- 비용: 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 기준 정하기 | 세무 상담 1회: 소득 구분(사업소득·기타소득), 사업자 등록 필요 여부, 적용 환율 기준, 인정 경비 범위, 부가세 대상 여부. **회사 겸업 규정도 함께 확인** | 기준을 설정 파일에 기록 |
| 1. 수익원 목록 | 26번 `projects.yaml`의 수익원별 정산 주기·통화·입금 계좌 정리 | 수익원 표 완성 |
| 2. 수입 집계 | 26번 수익 데이터 + 은행 입금 CSV 대조 (정산액과 입금액 차이 = 수수료·환전 차이 기록) | 월별 수입이 입금 내역과 일치 |
| 3. 환율 환산 | ECOS 환율 저장, 설정한 기준으로 외화 수입 원화 환산, 근거(날짜·환율) 함께 저장 | 모든 외화 수입에 환산 근거 |
| 4. 경비 태그 | 6번 카드 데이터 가맹점 → 프로젝트 태그, 해외 인보이스 메일 자동 수집 | 상위 경비 항목 100% 태그·증빙 연결 |
| 5. 월별 장부 | 간편장부 형식 파일 + 증빙 폴더 링크 자동 생성 | 3개월 연속 자동 생성 |
| 6. 예측 알림 | 누적 수입 기준 예상 종합소득세, **부업 소득이 커져 직장 건강보험료가 추가로 부과되는 기준(보수 외 소득 연 2,000만 원 초과)에 가까워지면 알림**, 사업소득이면 11월 중간예납 안내 | 월간 예측 리포트 |
| 7. 5월 신고 패키지 | 수입·경비 합계, 증빙 목록, 홈택스 입력 순서 체크리스트 | 2시간 안에 신고 준비 완료 |
| 8. 연간 회고 | 실제 신고 결과와 예측 비교, 다음 해 설정 파일 갱신 | 오차 10% 이내 |

## 법·정책 주의사항
- 이 도구는 신고 **준비 보조**: 최종 신고 내용의 판단·책임은 본인 또는 세무사
- 소득 구분, 사업자 등록, 부가세, 환율 기준은 상황마다 다르므로 첫해 전문가 확인 필수
- 금융·소득 데이터는 로컬·비공개 보관, 데이터 폴더 `.gitignore`

## 리스크와 대응
- 정산액과 실제 입금액 불일치 → 차이를 수수료·환차로 분리 기록해 근거 유지
- 경비 오분류(개인 지출 섞임) → 애매한 건은 "확인 필요"로 두고 월 1회 검토
- 세법 변경 → 매년 1월 설정 파일 검토 체크리스트
