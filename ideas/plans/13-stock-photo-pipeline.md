# 13. 직접 찍은 사진 스톡 판매 파이프라인

## 최종 목표
- **12개월 안에 승인된 사진 1,000장, 월 라이선스 수익 5만~10만 원**
- 사진 1장당 사람 손이 가는 시간 **30초 이하** (최종 확인만), 나머지는 자동
- 심사 승인율 70% 이상, "잘 팔리는 주제" 데이터로 촬영 방향 개선

## MVP 범위
- 스톡 사이트 1곳(Adobe Stock 기여자 등)부터 시작
- 사진 폴더 → 품질·위험 필터 → AI 메타데이터(제목·키워드) → 메타데이터를 파일에 삽입 → 업로드 → 심사 결과 기록

## 기술 구조
- 언어: Python
- 품질 필터: 해상도(사이트 최소 기준 이상), 흐림 감지(라플라시안 분산), 노출, 중복 제거(지각 해시)
- 위험 필터:
  - 얼굴 감지 → 모델 동의서 필요 표시 (동의서 없으면 상업용 제외)
  - 로고·상표·간판 글자 감지(OCR) → 제외 또는 에디토리얼 전용으로 분류
  - **GPS 위치정보 제거** (집 근처 사진의 위치 노출 방지)
- 메타데이터: 비전 기능이 있는 LLM으로 영문 제목·설명, 키워드 25~50개(중요도 순), 카테고리 생성. 한국적 장면은 "Korean food", "Seoul street" 같은 키워드를 우선
- 삽입: exiftool로 IPTC/XMP에 기록
- 업로드: 사이트가 제공하는 SFTP·FTP 업로드나 CSV 메타데이터 일괄 등록을 사용 (사이트별 지원 방식 확인, 비공식 자동화 금지)
- 기록: SQLite (사진·업로드 사이트·심사 결과·거절 사유·판매 내역)
- 비용: 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 계정·규정 | 기여자 계정 개설, 사이트별 해상도·파일 형식·키워드 수·업로드 방식·로열티율 정리, 세금 정보 제출(미국 사이트는 W-8BEN 등) | 사이트별 규정표 1장 |
| 1. 사진 모으기 | 사람이 안 나온 여행·음식·풍경·사물 사진 100장을 입력 폴더로 | 첫 배치 100장 |
| 2. 품질·위험 필터 | 해상도·흐림·노출·중복 필터, 얼굴·로고 감지, GPS 제거 | 필터 결과를 직접 검수해서 오판 10% 이하 |
| 3. 메타데이터 생성 | 제목·설명·키워드 자동 생성, 사람이 30초 안에 확인·수정하는 간단한 화면 | 1장 확인 30초 이내 |
| 4. 파일 삽입·업로드 | exiftool 삽입 → 공식 업로드 경로로 일괄 업로드 → 사이트에서 제출 | 100장 제출 완료 |
| 5. 심사 결과 반영 | 승인·거절과 거절 사유 기록, 거절 사유별로 필터 기준 조정 | 두 번째 배치부터 승인율 상승 |
| 6. 판매 분석 | 월 1회 기여자 대시보드 판매 내역 내려받기 → 주제·키워드별 판매 집계 | "잘 팔리는 주제 Top 5" 리포트 |
| 7. 촬영 가이드 | 판매 데이터 기반 "이번 달 찍으면 좋은 장면" 목록 (계절·명절·한국 일상) | 월간 가이드 자동 생성 |
| 8. 사이트 확장 | 같은 메타데이터로 두 번째·세 번째 스톡 사이트에 등록 (국내 스톡 포함) | 사이트 3곳, 승인 1,000장 |

## 법·정책 주의사항
- **알아볼 수 있는 사람**이 나오면 모델 동의서, 사유지·건축물·작품은 재산 동의서가 필요할 수 있음 → 없으면 상업용 등록 금지
- 상표·로고가 보이면 상업용 거절 사유 → 에디토리얼로만 등록하거나 제외
- 사이트별 AI 관련 정책 확인: 사진은 직접 촬영한 원본만 올리고, AI로 생성·합성한 이미지를 섞지 않음 (메타데이터 작성에만 AI 사용)
- 해외 로열티 수입은 소득 신고 대상: 신고 방법은 세무 상담으로 확인

## 리스크와 대응
- 장당 수익이 낮음 → 수량과 꾸준함이 핵심이라 처리 시간을 최소화하는 게 이 파이프라인의 존재 이유
- 키워드 스팸으로 계정 제재 → 사진에 실제로 보이는 것만 키워드로, 개수는 사이트 권장 범위 안에서
- 심사 기준 변경 → 거절 사유 기록으로 빠르게 감지하고 필터 조정
