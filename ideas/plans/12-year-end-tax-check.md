# 12. 연말정산 절세 월간 점검

## 최종 목표
- **매년 놓치는 공제 0건, 받을 수 있는 공제를 한도까지 채워 결정세액 최소화**
- 매달 "올해 남은 공제 여력"과 "이번 달 할 일"이 자동으로 나옴, 입력은 **월 5분 이하**
- 11월 말까지 "12월 31일 전에 할 일" 목록 확정 (연금 추가 납입액, 카드 사용 전략 등)
- 6번(고정비)·17번(금리)과 같은 데이터로 **월간 통합 재정 리포트** 완성

## MVP 범위
- 6번의 정규화된 카드 사용 데이터 재사용 → 신용카드·체크카드·현금영수증·전통시장·대중교통·도서공연별 집계
- 연금저축·IRP·주택청약·월세·의료비는 월 1회 간단 입력
- 총급여 대비 카드 사용 문턱(25%) 진행률, 연금 세액공제 한도 잔여액 알림

## 기술 구조
- **세법 수치는 코드에 넣지 않고 연도별 설정 파일(YAML)로 분리**: 공제율·한도·문턱이 매년 바뀔 수 있으므로 매년 1회 검토 후 갱신
  - 예: 카드 소득공제 문턱(총급여의 25%), 결제수단별 공제율, 연금계좌 세액공제 납입 한도(연금저축 600만 원, IRP 합산 900만 원)와 공제율(총급여 구간별) 등
- 데이터: 6번 파이프라인의 정규화 테이블 + 수동 입력 시트(연금·청약·월세·의료비·기부금)
- 계산: Python, 간이 결정세액 시뮬레이터 (근로소득공제 → 인적공제 → 소득공제 → 세율 → 세액공제)
- 검증: 홈택스 "연말정산 미리보기"(매년 하반기 제공)와 1월 "간소화 자료"로 대조
- 실행: 로컬 또는 비공개 저장소, 월 1회 자동 실행 + 텔레그램 요약
- 비용: 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 기준선 | 홈택스에서 작년 근로소득 원천징수영수증 확인: 총급여, 받은 공제, 못 받은 공제 | "작년에 놓친 공제" 목록 + 결정세액 기록 |
| 1. 세법 설정 파일 | 올해 기준 공제율·한도·문턱을 YAML로 정리, 출처(국세청 안내) 메모 | 설정 파일만 바꾸면 계산이 바뀌는 구조 |
| 2. 카드 데이터 연결 | 6번 정규화 데이터에 결제수단·공제 구분(전통시장·대중교통·도서공연 등) 태그 추가 | 월별 공제 구분별 사용액 집계 |
| 3. 수동 입력 시트 | 연금저축·IRP·주택청약·월세·의료비·기부금 월 입력 양식 | 1회 입력 5분 이내 |
| 4. 시뮬레이터 | 예상 결정세액 계산, "연금 X원 추가 납입 시 Y원 절세" 같은 what-if | 작년 원천징수영수증을 넣었을 때 실제 결정세액과 오차 5% 이내 |
| 5. 월간 알림 | 카드 25% 문턱 진행률(문턱 전에는 혜택 좋은 카드, 넘은 뒤에는 공제율 높은 체크카드·현금영수증 권장), 연금 공제 한도 잔여액 | 매달 1일 자동 발송 |
| 6. 11월 집중 모드 | 홈택스 미리보기 자료와 대조, 12월 31일까지 할 일 목록과 예상 절세액 | 할 일 목록 확정 |
| 7. 1월 대조 | 간소화 자료와 비교, 간소화에 안 나오는 항목(안경·교복 구입비, 일부 기부금 등) 영수증 챙기기 체크리스트 | 누락 0건으로 제출 |
| 8. 통합 리포트 | 6번(고정비)·17번(금리)과 합친 월간 재정 리포트 | 한 번 입력으로 리포트 1개 |

## 법·정책 주의사항
- 세법은 매년 개정되므로 계산 결과는 참고용: 최종 판단은 국세청 안내·홈택스 미리보기 기준
- 공제 요건(무주택 세대주 여부, 부양가족 소득 요건 등)은 개인 상황에 따라 달라서 판정이 애매하면 "확인 필요"로 표시
- 금융·소득 데이터는 로컬·비공개 보관, 데이터 폴더 `.gitignore`

## 리스크와 대응
- 세법 수치 오류 → 매년 1월 설정 파일 검토 체크리스트, 출처 링크 함께 저장
- 시뮬레이터 단순화로 인한 오차 → 작년 실제 데이터로 오차 검증 후 사용
- 간편결제 경유 사용분의 결제수단 구분 어려움 → 6번의 간편결제 내역 합치기 단계 활용
