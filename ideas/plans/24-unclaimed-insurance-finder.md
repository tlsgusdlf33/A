# 24. 실손보험 미청구 보험금 찾기 도우미

## 최종 목표
- **최근 3년 안의 미청구 실손보험금을 전부 찾아 청구 완료** (보험금 청구권은 3년이 지나면 소멸)
- 이후 진료분은 **미청구 0건**: 진료 후 7일 안에 청구 알림
- 영수증 1건 등록 30초 이하, 계산·추적은 자동
- 청구 자체는 실손24나 보험사 앱에서 본인이 직접 (본인인증이 필요하므로 자동 제출하지 않음)

## MVP 범위
- 내 실손보험 조건 설정 파일
- 영수증 사진 → 항목 추출 → 청구 가능액 추정 → 상태 관리(미청구 / 청구함 / 지급 / 거절)
- 미청구 목록과 3년 기한 알림

## 기술 구조
- 보험 조건: **가입 시기(세대)·약관에 따라 자기부담률, 공제금액, 보장 한도, 특약이 다르므로 코드에 넣지 않고 설정 파일로 관리** (내 보험 약관·증권에서 직접 확인해서 입력, 18번에 증권이 있으면 거기서 불러오기)
- 입력: 진료비 계산서·영수증(법정 서식이라 형식이 비교적 일정), 진료비 세부산정내역(비급여 항목 확인용), 약제비 영수증
- 추출: 비전 기능이 있는 LLM → 진료일, 기관명, 입원·외래 구분, 급여 본인부담금, 비급여 금액, 합계 → **합계 = 항목 합 검증**
- 계산: 설정된 약관 조건으로 청구 가능액 추정, 보장 여부가 애매한 항목(미용, 건강검진, 일부 비급여 특약 항목 등)은 "확인 필요"로 표시
- 누락 탐지: 12번에서 쓰는 연말정산 간소화 의료비 자료(기관별 연간 금액)와 대조해 영수증이 빠진 진료 찾기
- 저장: SQLite + 원본 이미지, **로컬 또는 비공개 저장소에서만**
- 알림: 텔레그램
- 비용: 거의 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 내 보험 조건 확인 | 보유 실손보험의 가입 시기, 자기부담률, 공제금액, 한도, 특약, 보험사별 청구 서류 기준(소액은 영수증만 등) 정리 | 설정 파일 완성 |
| 1. 영수증 모으기 | 최근 3년 영수증 사진 수집, 분실분은 병원·약국 재발급 가능 여부 확인 | 영수증 폴더 준비 |
| 2. 추출·검증 | 영수증 → 구조화 데이터, 합계 검증 실패 시 "확인 필요" | 샘플 20건 금액 정확도 95% 이상 |
| 3. 청구 가능액 계산 | 약관 조건 적용, 항목별 계산 근거 표시 | 이미 지급받은 과거 청구 5건과 비교해서 오차 10% 이내 |
| 4. 상태 관리 | 미청구 / 청구함 / 지급 / 거절 + 실제 지급액 기록, 차이가 나면 계산 규칙 보정 | 3년치 미청구 목록 확정 |
| 5. 누락 탐지 | 연말정산 의료비 자료(연도별·기관별)와 대조해 영수증 없는 진료 찾기 | 누락 진료 목록 생성 |
| 6. 청구 실행 | 미청구 목록을 실손24·보험사 앱에서 청구 (금액 큰 순서, 기한 임박 순서) | 3년치 미청구분 청구 완료 |
| 7. 알림 | 새 영수증 등록 후 7일 내 미청구면 알림, 청구 기한 6개월 전 알림, 청구 후 일정 기간 지급 없으면 확인 알림 | 신규 진료 미청구 0건 |
| 8. 18번 연동 | 보험 증권에서 보장 조건 자동 불러오기, 보험 갱신·변경 시 설정 자동 업데이트 알림 | 조건 수동 입력 불필요 |

## 법·정책 주의사항
- 진료 기록은 개인정보보호법상 **민감정보**: 로컬·비공개 보관, 저장 시 암호화 권장, 데이터 폴더 `.gitignore`
- LLM API로 영수증을 보낼 때는 서비스의 데이터 보관·학습 정책 확인, 필요하면 이름·주민번호 부분을 가리고 전송
- 계산 결과는 추정치이며 실제 지급액은 보험사 심사로 결정
- 보험사 시스템 자동 로그인·자동 청구는 하지 않음 (본인인증·약관 문제)

## 리스크와 대응
- 약관 조건 입력 오류 → 3단계에서 과거 실제 지급 내역으로 검증
- 비급여 항목의 보장 여부 판단 어려움 → "확인 필요"로 남기고 보험사 문의 체크리스트 제공
- 영수증 분실 → 5단계 누락 탐지로 진료 사실을 찾고 재발급 요청 목록 생성
