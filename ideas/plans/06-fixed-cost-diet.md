# 06. 고정비 다이어트 자동 점검

## 최종 목표
- **3개월 안에 월 고정비 10% 이상 절감**, 절감액을 리포트에 누적 표시
- 매월 해야 할 일은 **카드 이용내역 파일을 폴더에 넣는 것 하나 (5분 이하)**, 나머지는 자동
- 12번(연말정산 절세)과 **같은 데이터 파이프라인을 공유**해서 한 번 입력으로 두 리포트 생성

## MVP 범위
- 카드사 1~2곳의 이용내역 엑셀/CSV 파서
- 반복 결제(구독) 자동 탐지 + 월간 리포트 1장 (구독 목록, 가격 인상, 중복 서비스, 해지 후보)

## 기술 구조
- 입력: 카드사 홈페이지·앱에서 내려받은 이용내역 파일
  - 마이데이터 API는 허가받은 사업자만 쓸 수 있으므로 개인 프로젝트는 파일 내려받기 방식
- 처리: Python (pandas) — 파서 → 정규화 → 분류 → 반복 결제 탐지 → 리포트
- 분류: 가맹점명 규칙 사전 우선, 애매한 건만 LLM으로 분류 후 결과를 사전에 저장 (다음 달부터 비용 0)
- 실행: **본인 PC에서 로컬 실행** 또는 비공개 저장소 (금융 데이터는 공개 레포·외부 서버에 올리지 않음)
- 출력: HTML 또는 마크다운 리포트, 원하면 메일 발송

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 확보 | 사용하는 카드사별 최근 3~6개월 이용내역 내려받기, 형식 차이 정리 | 카드사별 샘플 파일 + 컬럼 매핑표 |
| 1. 파서·정규화 | 날짜·가맹점·금액·할부·해외결제 여부를 공통 스키마로 변환, 취소 건 상계 | 모든 파일이 하나의 표로 합쳐짐, 합계가 명세서와 일치 |
| 2. 가맹점 정규화 | "NETFLIX.COM", "넷플릭스" 같은 표기를 하나로 묶는 사전 | 상위 50개 가맹점 정규화 |
| 3. 반복 결제 탐지 | 같은 가맹점 + 비슷한 금액 + 약 30일(또는 365일) 간격 패턴 | 알고 있는 구독이 빠짐없이 탐지됨 |
| 4. 절감 포인트 탐지 | 금액 인상, 같은 종류 중복 구독(OTT·클라우드 등), 무료 체험 후 유료 전환, 해외결제 수수료, 연회비 | 항목별 예상 절감액 계산 |
| 5. 월간 리포트 | 고정비 총액 추이, 해지 후보 체크리스트, 누적 절감액 | 첫 리포트로 실제 해지 1건 이상 |
| 6. 자동화 | 지정 폴더에 파일을 넣으면 자동 실행, 매달 1일 "파일 넣을 차례" 알림 | 2개월 연속 5분 안에 리포트 완성 |
| 7. 12번과 통합 | 같은 정규화 데이터로 신용/체크카드 비율·공제 항목 집계 모듈 추가 | 한 번 입력으로 리포트 2종 |
| 8. (선택) 공개 버전 | 브라우저 안에서만 처리하는 웹앱(파일이 서버로 안 감)으로 공개, 광고·제휴 연결 | 개인정보를 서버에 저장하지 않는 구조 검증 |

## 법·정책 주의사항
- 금융 거래 내역은 민감 정보: 로컬·비공개 보관, `.gitignore`로 데이터 폴더 제외
- 공개 버전을 만들 경우 서버 저장 없이 클라이언트에서 처리하고, 처리 방식을 개인정보처리방침에 명시

## 리스크와 대응
- 카드사 파일 형식 변경 → 카드사별 파서를 분리하고 형식 검증 실패 시 알림
- 간편결제(네이버페이·카카오페이 등) 경유 결제는 가맹점명이 가려짐 → 간편결제 내역 파일을 추가로 합치는 단계 준비
- 오탐 → 사용자가 "구독 아님" 표시하면 다음부터 제외
