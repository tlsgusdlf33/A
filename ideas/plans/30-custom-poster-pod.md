# 30. 데이터 기반 맞춤 포스터 주문형 인쇄 판매

## 최종 목표
- **6개월 안에 월 주문 30건, 건당 마진 1만 원 이상 (월 30만 원 이상)**
- 주문 접수 → 인쇄 파일 생성 → 인쇄 업체 전달 → 송장 안내까지 **사람 손 0** (예외 처리만)
- 인쇄 불량·재제작률 3% 이하, 별자리 위치는 천문 소프트웨어와 대조해 정확

## MVP 범위
- 상품 2종: 별자리 포스터(날짜·시간·장소의 밤하늘), 지도 포스터(장소 중심 도로망)
- 템플릿 3종, 한글 문구(이름·날짜·메시지), 크기 2종(A3·A4)
- 자체 웹사이트의 실시간 미리보기 + 결제 + 인쇄 업체 자동 전달

## 기술 구조
- 별자리 렌더링: 공개 별 목록(퍼블릭 도메인 성표)과 천문 계산 라이브러리(Python skyfield 또는 JS d3-celestial 등 라이선스 확인)로 해당 시각·위치의 하늘 계산 → SVG
- 지도 렌더링: 오픈스트리트맵 데이터(대량 사용 시 공개 API 대신 국내 지역 추출본 사용) → 도로·물길 스타일링 → SVG, **"© OpenStreetMap contributors" 표기**
- 인쇄 파일: SVG → 300dpi PDF, 상업 이용 가능한 한글 폰트(OFL 라이선스 등)
- 웹: Next.js, 브라우저에서 실시간 미리보기 → 결제(국내 PG) → 서버에서 고해상도 파일 생성
- 인쇄 연동: 국내 주문형 인쇄 업체의 API 또는 주문 파일 자동 업로드 방식 (업체별 지원 여부를 0단계에서 확인), 없으면 해외 주문형 인쇄 API는 배송비·기간 비교 후 보조로
- 주문 관리: 주문 상태(결제 → 파일 생성 → 인쇄 접수 → 발송), 송장 번호 고객 안내
- 판매 채널 확장: 스마트스토어(커머스 API로 주문 자동 수집) 등
- 운영 감시: 26번 운영 연동 표준 적용
- 비용: 호스팅 무료~소액, 인쇄·배송비는 주문당 원가

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 인쇄 업체 조사 | 국내 업체 2~3곳 단가·용지·연동 방식 비교, 샘플 인쇄(색감·별 크기·얇은 선 표현) | 업체 1곳 확정, 원가표 |
| 1. 별자리 렌더러 | 날짜·시간·위경도 → 별·별자리선·은하수(선택), 천문 소프트웨어 화면과 대조 | 샘플 10건 위치 일치 |
| 2. 지도 렌더러 | 중심 좌표·축척 → 도로·물길·공원, 출처 표기 자동 삽입 | 서울·지방 도시 각 3곳 렌더링 품질 확인 |
| 3. 템플릿·문구 | 템플릿 3종, 한글 문구 배치·글자 수 제한·줄바꿈 | 디자인 검수 통과 |
| 4. 미리보기·결제 | 입력 → 실시간 미리보기 → 옵션 선택 → 결제, 맞춤 제작 상품의 청약철회 제한 **사전 고지** | 테스트 결제 성공 |
| 5. 인쇄 자동 전달 | 결제 완료 → 300dpi PDF 생성 → 인쇄 업체로 자동 전달 → 접수 확인 | 테스트 주문 3건 무인 처리 |
| 6. 배송·고객 안내 | 송장 수집 → 문자·메일 안내, 불량 접수 양식 | 실주문 10건 처리, 불량률 측정 |
| 7. 판매 채널 | 스마트스토어 입점(주문 자동 수집), 기념일·연말 시즌 소액 광고 테스트 | 월 주문 10건 |
| 8. 확장 | 액자 옵션, 저가 디지털 파일 옵션, 웨딩·돌잔치 묶음 상품 | 월 주문 30건 |

## 필요한 계정·비용
- 사업자 등록·통신판매업 신고(실물 판매), 국내 PG, 인쇄 업체 계정, 도메인, (확장 시) 스마트스토어

## 법·정책 주의사항
- 실물 판매이므로 **사업자 등록·통신판매업 신고** 필요, 회사 겸업 규정 확인
- 전자상거래법: 맞춤 제작 상품은 청약철회가 제한될 수 있지만 **구매 전에 명확히 고지**해야 함, 인쇄 불량은 교환·환불
- 오픈스트리트맵 데이터는 ODbL 라이선스에 따라 출처 표기, 폰트·별 데이터·라이브러리 라이선스 확인
- 배송지 등 개인정보는 배송 완료 후 최소 기간만 보관

## 리스크와 대응
- 인쇄 품질 편차 → 샘플 인쇄로 선 굵기·색상 기준 확정, 불량 사진 접수 시 자동 재제작
- 시즌 편중 → 시즌 전 재고가 필요 없는 구조라 광고만 집중
- 인쇄 업체 API 부재 → 주문 파일 자동 생성 + 업체 대량 주문 업로드로 반자동 시작
