# 16. 한국 특화 데이터 API 종량제 판매

## 최종 목표
- **12개월 안에 API 3종 운영, 유료 사용자 20명, 월 매출 20만 원 이상**
- 가용성 99.9%, 장애 감지부터 알림까지 자동, 운영은 **주 1시간 이하**
- API 1종 추가에 드는 시간을 주말 이틀 이내로 줄이는 공통 틀(인증·과금·문서·테스트) 확보

## 어떤 API부터 만들까
외부 데이터에 의존하지 않는 **자체 로직 API**부터 시작합니다. 남의 데이터를 되파는 구조보다 약관 리스크가 작고 원가가 0에 가깝습니다.

| 우선순위 | API | 이유 |
|---|---|---|
| 1 | 한국 영업일 계산 (공휴일·대체공휴일·임시공휴일 반영, N영업일 후 날짜) | 결제·배송·정산 시스템에서 꾸준히 필요, 해외 라이브러리는 대체공휴일·임시공휴일을 잘 못 따라감 |
| 2 | 한글 이름·주소 로마자 변환 (국어의 로마자 표기법 기준 + 흔한 성씨 관용 표기 옵션) | 해외 배송·여권·글로벌 서비스 가입 폼에서 수요 |
| 3 | 사업자등록번호 형식·체크섬 검증 (+ 선택: 국세청 상태조회 연동) | B2B 가입 폼 필수 기능. 상태조회는 공공데이터 이용허락 범위 확인 후 추가 |

## 기술 구조
- 런타임: Cloudflare Workers (TypeScript + Hono), 응답 지연 최소, 무료 티어로 시작
- 데이터: 공휴일 표는 Workers KV에 연도별 저장, 매년·임시공휴일 발표 시 갱신 (공공데이터 특일정보 API로 자동 확인 + 사람 검수)
- 명세: OpenAPI 3 문서를 먼저 쓰고 코드·문서·SDK를 거기서 생성
- 판매: API 마켓플레이스(RapidAPI 등)에서 키 발급·요금제·결제를 대행. 수수료율과 정산 방식은 등록 전에 확인
- 모니터링: 외부 업타임 체크 + 오류율 알림(텔레그램)
- 비용: 초기 월 0원 ~ 수천 원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 수요 검증 | 개발 커뮤니티 질문, GitHub 유사 라이브러리 스타·이슈, 기존 유료 API 가격 조사 | API 후보별 "누가, 왜, 얼마에" 1줄 정리 |
| 1. API 설계 | 엔드포인트·파라미터·에러 형식을 OpenAPI로 작성 | 명세만 보고 호출 예제를 쓸 수 있음 |
| 2. 핵심 로직 + 테스트 | 영업일: 2015년 이후 공휴일·대체공휴일 표로 회귀 테스트. 로마자: 국립국어원 표기 예시로 정확도 테스트 | 테스트 세트 100% 통과 |
| 3. 배포 | Workers 배포, 요청 제한, 구조화 로그, 입력값 미저장 | 1초 이내 응답, 부하 테스트 통과 |
| 4. 마켓 등록 | 요금제 설계 (예: 무료 월 500회 / 유료 단계별), 설명·예제(curl, JS, Python) | 마켓에 공개, 무료 사용자 첫 가입 |
| 5. 문서·SDK | 문서 사이트, npm·PyPI용 얇은 클라이언트(오픈소스) | 설치 후 3줄로 호출 가능 |
| 6. 알리기 | 개발 커뮤니티에 "왜 만들었는지" 직접 쓴 글, 오픈소스 저장소 README에서 API 안내 | 무료 사용자 50명 |
| 7. 운영 자동화 | 업타임·오류율 알림, 공휴일 갱신 자동 확인, 월간 사용량 리포트 | 30일 무개입 운영 |
| 8. 확장 | 2·3번째 API 추가, 사용량이 커지면 자체 결제(국내 PG)로 수수료 절감 검토 | API 3종, 유료 20명 |

## 필요한 계정·API·비용
- Cloudflare, API 마켓플레이스 판매자 계정, GitHub, npm·PyPI, (선택) 공공데이터포털
- 해외 마켓 정산 수령 계좌, 매출이 생기면 사업자 등록·소득 신고 방식은 세무 상담으로 확인

## 법·정책 주의사항
- 공공데이터를 감싸서 팔 때는 데이터별 이용허락 범위(상업적 이용·재배포 가능 여부)와 출처 표시 의무 확인
- 이름·주소 입력값은 개인정보일 수 있으므로 **저장·로그 기록하지 않음**을 문서에 명시
- 정확성 면책 조항: 법적 효력이 있는 판단(예: 법정 기한 계산)에 단독 사용하지 않도록 안내

## 리스크와 대응
- 수요가 작을 수 있음 → 0단계 검증에서 반응 없는 API는 만들지 않음
- 임시공휴일 반영 지연 → 발표 감지 알림 + 24시간 내 반영 목표
- 마켓 정책·수수료 변경 → 코어 로직과 판매 채널을 분리해 채널 교체 가능하게
