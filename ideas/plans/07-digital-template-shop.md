# 07. 디지털 템플릿 자동 판매

## 최종 목표
- **6개월 안에 템플릿 5종 출시, 월 판매 30건, 월 매출 30만 원 이상**
- 결제 → 파일 발송 → 사용 안내 → 자주 묻는 질문 응답까지 자동, 운영은 **주 1시간 이하**
- 첫 템플릿은 이미 채택한 재정 자동화(6·12·17번)를 엑셀·노션 버전으로 만든 것: 직접 쓰면서 검증된 템플릿이 가장 잘 팔림

## MVP 범위
- 템플릿 1종 (예: "자동 분류 가계부 + 고정비 점검 + 연말정산 공제 체크" 엑셀)
- 판매 플랫폼 1곳 + 자동 발송 + 사용 가이드 PDF + 미리보기 이미지 5장

## 기술 구조 (Claude Code가 만들 부분)
- 템플릿 자체: 엑셀 수식·조건부 서식·드롭다운·차트, 노션은 데이터베이스·수식·뷰 구성
- 템플릿 생성 스크립트: Python(openpyxl)으로 템플릿을 코드로 생성 → 수정·버전 관리·변형판(카드사별 등) 제작이 쉬워짐
- 상세페이지 소재: 샘플 데이터를 넣은 화면 캡처·GIF 자동 생성
- 판매 채널: 노션 템플릿 마켓플레이스, Gumroad·Lemon Squeezy 같은 디지털 상품 플랫폼, 국내 재능마켓 중에서 선택
  - 플랫폼별 수수료, 정산 방식(국내 계좌·해외 송금), 디지털 상품 허용 여부를 먼저 비교
- 이후 자체 판매 페이지(국내 PG 결제 + 결제 완료 웹훅 → 다운로드 링크 메일 자동 발송)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 시장 조사 | 노션 마켓·재능마켓 인기 템플릿의 가격대, 리뷰 속 불만 수집 | "기존 템플릿의 불만 3가지 + 내 템플릿이 해결하는 방법" 정리 |
| 1. 첫 템플릿 제작 | 본인이 실제로 쓰는 양식을 코드로 생성, 샘플 데이터 포함 | 본인이 2주간 실사용, 오류 0건 |
| 2. 품질 마감 | 사용 가이드(PDF 5쪽 이내), 처음 여는 사람용 "시작하기" 시트, 버전 표기 | 지인 3명이 설명 없이 10분 안에 사용 시작 |
| 3. 상세페이지 | 문제 → 해결 → 미리보기 → 포함 내용 → FAQ 순서, 캡처·GIF 자동 생성 | 상세페이지 완성, 환불 정책·청약철회 제한 고지 포함 |
| 4. 등록·자동 발송 | 플랫폼 등록, 결제 후 자동 다운로드, 구매자에게 안내 메일 | 테스트 구매로 전 과정 무인 동작 확인 |
| 5. 문의 자동화 | 자주 묻는 질문 10개 답변 문서, 문의 메일 자동 분류·답변 초안 | 문의 응답 1건 5분 이내 |
| 6. 리뷰·개선 | 구매 7일 후 사용 팁 + 리뷰 요청 메일, 피드백 반영해 업데이트 | 리뷰 10개, 평점 4.5 이상 |
| 7. 라인업 확장 | 같은 생성 스크립트로 변형판·관련 템플릿 추가, 묶음 할인 | 템플릿 5종, 묶음 상품 1개 |
| 8. 자체 판매 페이지 | 판매가 안정되면 수수료 절감을 위해 자체 결제 페이지 추가 | 자체 채널 매출 비중 30% |

## 필요한 계정·비용
- 판매 플랫폼 판매자 계정, 정산 계좌, (자체 판매 시) 국내 PG, 도메인
- 비용: 초기 0원 ~ 월 수천 원, 플랫폼 판매 수수료 별도

## 법·정책 주의사항
- 매출이 반복되면 사업자 등록·통신판매업 신고가 필요할 수 있음 (플랫폼·규모에 따라 다르므로 확인)
- 전자상거래법: 디지털 콘텐츠는 제공이 시작되면 청약철회가 제한될 수 있지만, **그 사실을 구매 전에 명확히 고지**해야 함
- 템플릿에 들어가는 폰트·아이콘·이미지의 상업적 이용 라이선스 확인

## 리스크와 대응
- 경쟁 템플릿이 많음 → "재정 자동화"처럼 내가 실제로 쓰는 좁은 주제로 차별화
- 엑셀 버전·OS 호환성 문제 → 엑셀·구글 시트 양쪽에서 동작 테스트, 지원 환경 명시
- 불법 공유 → 가격을 낮게 유지하고 업데이트·지원을 구매자 혜택으로
