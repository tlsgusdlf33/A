# 19. 공모주 청약 자동 분석 & 알림

## 최종 목표
- **청약할 공모주를 점수로 골라, "점수 상위 종목의 상장일 평균 수익률 > 전체 공모주 평균"을 12개월 동안 유지**
- 점수 상위만 청약해서 손실 종목 비율 20% 이하
- 공모주 1건당 판단 시간 **1분 이하** (알림 확인 → 청약 여부 결정), 데이터 수집·분석은 100% 자동
- 매매·청약 자체는 자동화하지 않음 (본인이 직접)

## MVP 범위
- DART에서 새 증권신고서(지분증권) 감지 → 일정·공모가 밴드·주관사 정리
- 수요예측 결과 공시 후 핵심 지표 추출 → 점수 → 청약 전날 텔레그램 알림
- 상장 후 시초가·종가 기록 (점수 검증용)

## 기술 구조
- 공시 데이터: 금감원 **DART Open API** (opendart.fss.or.kr, 무료 인증키)
  - 공시검색 API로 발행공시(증권신고서·정정신고서·투자설명서·증권발행실적보고서) 감지
  - 증권신고서 주요정보 API + 공시 원문(문서 다운로드)에서 수치 추출
- 상장 후 시세: 공공데이터포털의 주식시세 정보 API 또는 KRX Open API (이용 조건 확인)
- 추출: 원문 표 파싱 우선, 형식이 제각각인 부분만 LLM으로 보조 추출 후 수치 검증
- 저장: SQLite (종목, 일정, 지표, 점수, 상장 후 성과)
- 알림: 텔레그램 봇
- 비용: 거의 0원

## 점수에 쓰는 지표 (초기 규칙 → 과거 데이터로 가중치 보정)
| 지표 | 의미 |
|---|---|
| 기관 수요예측 경쟁률 | 기관 수요의 강도 |
| 의무보유확약 비율 | 기관이 상장 직후 팔지 않겠다고 약속한 비율 |
| 상장일 유통가능 물량 비율 | 상장 첫날 시장에 풀릴 수 있는 물량 |
| 확정 공모가의 희망밴드 내 위치 | 밴드 상단 초과·하단 미달 여부 |
| 구주매출 비중 | 기존 주주가 파는 비중 (높으면 주의) |
| 공모 규모·시가총액 | 수급 부담 |

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 인증키·데이터 확인 | DART 인증키 발급, 증권신고서·정정신고서·증권발행실적보고서 원문 구조 확인 | 최근 공모주 3건의 원문에서 지표 위치 파악 |
| 1. 공시 감지 | 매일 발행공시 검색 → 지분증권 공모 건만 필터 → 종목 등록 | 새 공모 일정을 놓치지 않음 (7일 검증) |
| 2. 지표 추출 | 원문 표 파싱 + LLM 보조, 수치 범위 검증(비율 0~100% 등) | 과거 30건 추출 결과를 직접 검수해서 95% 이상 정확 |
| 3. 과거 데이터 백필 | 최근 2~3년 공모주의 지표 + 상장일 시초가·종가 수집 | 백테스트용 데이터셋 완성 |
| 4. 점수 모델 | 규칙 기반 점수 → 백테스트로 가중치 조정 (단순하게 유지, 과적합 주의) | 점수 상위 그룹 평균 수익률 > 전체 평균 (과거 데이터 기준) |
| 5. 알림 | 청약 전날: 점수·핵심 지표·주관 증권사·균등배정 최소 증거금·환불일·상장일 | 실제 청약 1건에 사용 |
| 6. 계좌 준비 알림 | 주관 증권사 계좌가 없으면 미리 알림 (증권사별 신규 계좌 청약 제한 규정 확인) | 계좌 문제로 놓치는 청약 0건 |
| 7. 성과 추적 | 상장 후 시초가·종가 자동 기록, 월간 "점수 vs 실제 수익" 리포트 | 3개월 실사용 성과 확인 |
| 8. 보정 | 분기마다 실제 결과로 가중치 재조정 | 12개월 목표 지표 달성 |

## 법·정책 주의사항
- **본인용 판단 도구로만 사용**: 분석 결과를 유료로 제공하거나 불특정 다수에게 추천하면 자본시장법상 유사투자자문업 신고 등 규제 대상이 될 수 있음
- DART·시세 API 이용약관(호출 한도, 재배포 조건) 준수
- 투자 손실 가능: 점수는 과거 데이터 기반 참고 지표이며 수익을 보장하지 않음

## 리스크와 대응
- 공시 형식이 회사마다 달라 추출 실패 → 실패 시 "수동 확인 필요" 알림, 원문 링크 첨부
- 시장 분위기에 따라 지표의 설명력이 변함 → 분기별 재보정
- 증거금이 묶이는 기간의 기회비용 → 17번(금리 알림)과 연결해 청약 대기 자금은 파킹통장에
