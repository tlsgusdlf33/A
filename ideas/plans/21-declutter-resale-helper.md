# 21. 안 쓰는 물건 현금화 도우미

## 최종 목표
- **3개월 안에 물건 30개 판매, 현금화 50만 원 이상**
- 물건 1개 판매 준비(사진 정리 → 가격 → 판매글)에 **5분 이하**
- 게시 후 판매까지 평균 14일 이하, 30일 넘게 안 팔리면 자동으로 가격 조정 제안

## MVP 범위
- 사진 3~5장 업로드 → 제품 식별·상태 설명 → 가격 3안 → 판매글 초안 → 복사
- 판매 상태 관리 (준비 / 게시 / 예약 / 판매완료) + 판매 결과 기록
- 게시는 본인이 각 중고거래 앱에서 직접 (자동 게시·크롤링 금지)

## 기술 구조
- 앱: 휴대폰에서 쓰기 쉬운 모바일 웹 (PWA), 혼자 쓰는 도구라 인증은 단순하게
- 제품 식별: 비전 기능이 있는 LLM → 카테고리, 브랜드, 모델명 추정, 구성품, 흠집·사용감 설명 → 사람이 확인
- 사진 처리: 밝기·크기 보정, 대표 사진 순서 제안, **사진 속 개인정보(택배 송장 이름·주소, 영수증) 자동 감지·가림**
- 새 제품 가격: 네이버 쇼핑 검색 API로 현재 최저가 조회
- 적정가: 카테고리별 감가 규칙(사용 기간, 상태 등급, 구성품 유무) + 본인이 앱에서 직접 본 비슷한 매물 가격을 참고값으로 입력 가능
- 가격 3안: 빠른 판매가 / 적정가 / 최대 기대가
- 판매글: 플랫폼별 말투·길이에 맞춘 초안 (제목, 상태, 구성품, 거래 방식, 하자 고지)
- 저장: SQLite 또는 Supabase (물건, 사진, 가격, 상태, 판매가, 소요일)
- 비용: 거의 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 물건 모으기 | 1년 넘게 안 쓴 물건 목록과 사진 (물건당 3~5장, 밝은 곳) | 물건 10개 사진 준비 |
| 1. 식별·설명 | 사진 → 제품 정보·상태 설명 → 확인·수정 화면 | 10개 중 8개 이상 모델명 정확 |
| 2. 개인정보 가림 | 송장·영수증·이름표 감지 후 가림, 위치정보 제거 | 테스트 사진에서 누락 0건 |
| 3. 가격 제안 | 새 제품 최저가 + 감가 규칙 → 가격 3안, 근거 표시 | 본인이 보기에 납득 가능한 가격 |
| 4. 판매글 생성 | 플랫폼별 초안, 하자·구성품 누락 없이 고지 | 복사 후 수정 없이 게시 가능한 비율 70% 이상 |
| 5. 판매 관리 | 상태 관리, 판매 결과(판매가·소요일) 기록, 30일 미판매 시 가격 인하 제안 | 첫 10개 판매 완료 |
| 6. 감가 모델 개선 | 실제 판매가로 카테고리별 감가 규칙 보정 | 제안 가격과 실제 판매가 차이 15% 이내 |
| 7. 다른 항목과 연결 | 18번(보증서) 데이터로 "보증 잔여 N개월" 판매글 자동 삽입, 6번(고정비)의 결제 내역으로 구입 시기 자동 추정 | 연동 1개 이상 동작 |

## 법·정책 주의사항
- 중고거래 앱의 자동 게시·크롤링은 약관 위반 → 게시와 시세 확인은 본인이 직접
- 플랫폼별 **판매 금지 품목**(의약품, 주류, 일부 건강기능식품·화장품 소분 등) 확인 후 판매
- 하자·사용감은 판매글에 사실대로 고지 (분쟁 예방)
- 개인 물건 처분 범위를 넘어 반복적으로 사들여 되파는 경우 사업자 등록·세금 문제가 생길 수 있음

## 리스크와 대응
- 모델명 오인식 → 확인 화면에서 바로 수정, 수정 내용은 다음 식별에 참고
- 감가 규칙이 실제 시세와 다름 → 판매 결과로 계속 보정, 시세 참고값 입력 기능
- 거래 사기 → 판매글에 안전결제·직거래 원칙 문구 기본 포함
