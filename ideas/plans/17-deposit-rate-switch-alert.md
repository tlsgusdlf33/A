# 17. 예적금·파킹통장 금리 자동 비교 & 갈아타기 알림

## 최종 목표
- **내 여유자금의 가중평균 금리를 "내가 가입 가능한 상품" 중 상위 10% 수준으로 유지**
- 더 좋은 상품이 공시되면 **24시간 안에** 알림, 만기 30일 전에는 갈아탈 상품 Top 3 자동 추천
- 연간 이자 증가분을 리포트에 누적 표시 (예: 예치금 2,000만 원, 금리 +1%p → 세전 연 20만 원)
- 운영 시간 0 (설정 파일만 가끔 수정)

## MVP 범위
- 금감원 금융상품통합비교공시 Open API로 정기예금·적금 수집 (은행 + 저축은행)
- 내 계좌 설정 파일 1개 + 텔레그램 알림 3종 (신규 고금리 / 내 금리보다 높은 상품 / 만기 임박 추천)

## 기술 구조
- 데이터: 금융상품통합비교공시(finlife.fss.or.kr) Open API — 인증키 무료 발급
  - 정기예금·적금 중심 API입니다. **파킹통장(수시입출금) 금리가 포함되는지 먼저 확인**하고, 없으면 MVP에서는 주요 파킹통장 금리를 설정 파일에 수동 입력
- 수집·비교: Python, 매일 1회 실행 (GitHub Actions 크론 또는 개인 PC 스케줄러)
- 저장: SQLite (상품·금리 이력)
- 우대조건 해석: 공시의 우대조건은 자유 텍스트 → LLM으로 "급여이체 필요", "신규 고객 한정" 같은 구조화 조건으로 변환해 캐시 (상품별 1회)
- 알림: 텔레그램 봇
- 비용: 거의 0원 (LLM 호출은 신규 상품에만)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 인증키 발급 | finlife Open API 키 신청, 응답 필드(기본금리·최고우대금리·저축기간·가입대상·우대조건) 확인 | 예금·적금 샘플 응답 저장, 파킹통장 포함 여부 확인 |
| 1. 수집기 | 금융권역(은행·저축은행)별·페이지별 전체 수집, 일별 스냅샷 저장 | 7일 연속 수집 성공, 금리 변경 이력 추적 가능 |
| 2. 내 프로필·계좌 설정 | 보유 계좌(금액·금리·만기일·중도해지 이율), 내 조건(급여이체 가능 은행, 비대면 가입 가능 여부, 거래 은행) | 설정 파일 1개로 정리 |
| 3. 우대조건 구조화 | 자유 텍스트 → 조건 목록 + "내가 충족 가능한가" 판정, 판정이 애매하면 기본금리만 인정 | 상위 30개 상품의 판정을 직접 검수해서 90% 이상 일치 |
| 4. 비교 엔진 | 세후 실수령 이자(이자소득세 15.4%) 기준 비교, 중도해지 손실 vs 갈아타기 이득 계산, 예금자보호 한도(금융회사별 1억 원, 2025년 9월 상향) 초과 여부 경고 | "지금 갈아타면 만기까지 순이득 N원"을 계산 |
| 5. 알림 | 신규 고금리, 내 금리보다 X%p 이상 높은 상품, 만기 D-30·D-7 추천 Top 3. 같은 알림 반복 금지 | 2주간 실사용, 알림 피로 없음 |
| 6. 주간 리포트 | 시장 금리 추이, 내 가중평균 금리 순위, 누적 이자 증가분 | 매주 자동 발송 |
| 7. 재정 세트 통합 | 6번(고정비)·12번(연말정산)과 같은 리포트로 묶기 | 월 1회 통합 재정 리포트 |

## 법·정책 주의사항
- 공시 데이터는 금융회사 보고 시점에 따라 늦게 반영될 수 있음 → 가입 전 은행 앱에서 실제 금리 확인을 알림에 명시
- **개인용으로 쓰는 건 문제없지만, 일반에 공개해서 상품 추천·가입 연결로 수익을 내면** 금융소비자보호법상 판매대리·중개업 등록 대상이 될 수 있음 → 공개 전 반드시 확인
- Open API 이용약관(호출 한도, 출처 표시) 준수

## 리스크와 대응
- 우대조건 오판정 → 판정 불확실 시 기본금리로 보수적 계산, 근거 문장을 알림에 함께 표시
- 특판 상품은 공시보다 빨리 마감 → 특판은 "빨리 확인" 표시로 구분
- 금리 하락기에는 갈아탈 상품이 없음 → 그때는 만기 연장 vs 다른 상품 비교로 알림 성격 전환
