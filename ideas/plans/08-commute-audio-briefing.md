# 08. 출퇴근 맞춤 오디오 브리핑

## 최종 목표
- **매일 오전 6시 30분까지 12~15분짜리 개인 브리핑 에피소드가 팟캐스트 앱에 자동으로 올라옴**
- 30일 연속 사람 손 없이 생성, 운영비 **월 1만 원 이하**
- 관심 분야의 중요한 소식을 놓치지 않으면서 하루 정보 소비 시간은 15분 안으로

## MVP 범위
- 소스: RSS 10개 이내 + 뉴스레터(전용 메일 라벨)
- 하루 상위 8개 소식 → 한국어 대본 → 음성 → 비공개 팟캐스트 피드
- 쇼노트에 원문 링크 목록

## 기술 구조
- 수집: Python (feedparser), 뉴스레터는 전용 메일 주소·라벨에서 가져오기
- 중복 제거·선별: 제목·본문 유사도로 중복 묶기 → 관심 키워드·최근 피드백 기반 점수 → 상위 8개
- 대본: LLM으로 소식별 2~3문장 요약 + 전체 흐름 연결, 각 소식마다 출처 언급
- 음성: 한국어 TTS (여러 서비스의 한국어 음성 품질·가격을 비교해서 선택), ffmpeg로 음량 정규화·인트로·챕터
- 배포: Cloudflare R2 등에 MP3 + RSS 피드 XML, **추측 불가능한 비공개 URL**
- 청취: URL로 팟캐스트를 추가할 수 있는 앱에서 구독
- 실행: 매일 05:30 (한국 시간) 크론, 실패 시 텔레그램 알림
- 피드백: 텔레그램으로 "이 주제 더/덜"을 보내면 다음 날 점수에 반영

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 소스 선정 | 업계 뉴스, 관심 기술 블로그, 구독 뉴스레터 목록과 RSS 주소 정리 | 소스 10개 이내, 각 소스의 갱신 빈도 확인 |
| 1. 수집기 | 최근 24시간 항목 수집, 본문 추출, 수집 실패 소스 표시 | 7일 연속 수집 성공 |
| 2. 선별 | 중복 묶기 + 점수화, 상위 8개 선택 | 직접 고른 상위 8개와 70% 이상 일치 |
| 3. 대본 생성 | 오프닝 → 소식 8개(각 1분 내외) → 한 줄 정리, 출처 언급, 숫자·고유명사 정확성 확인 | 대본 1개가 12~15분 분량 |
| 4. 음성·오디오 | TTS 음성 비교 후 선택, 문장 단위 합성 → 합치기 → 음량 정규화 | 출퇴근 중 듣기에 거슬림 없음 |
| 5. 비공개 피드 | RSS 피드 생성(에피소드·쇼노트·원문 링크), 비공개 URL 배포, 앱에서 구독 | 앱에 다음 날 에피소드 자동 표시 |
| 6. 스케줄·감시 | 매일 05:30 실행, 단계별 실패 알림, 실패 시 전날 소식 재사용 금지 | 30일 무개입 운영 |
| 7. 피드백 루프 | 텔레그램 "더/덜" 명령 → 주제 가중치 조정 | 2주 후 선별 만족도 체감 상승 |
| 8. 확장 | 주말 주간 정리판, 영어 소스 → 한국어 브리핑, 오디오 속도별 버전 | 주간판 자동 생성 |

## 필요한 계정·비용
- LLM API, TTS API, 객체 저장소(R2 등), 텔레그램 봇, 크론 실행 환경
- 비용: 하루 15분 음성 기준 TTS·LLM 합쳐 월 수천 원~1만 원 수준 (서비스별 단가 확인)

## 법·정책 주의사항
- 원문 기사·뉴스레터를 요약해 음성으로 만드는 건 **본인 청취용으로만**: 피드를 공개하거나 팟캐스트 디렉터리에 등록하면 저작권 문제
- 유료 뉴스레터의 이용약관(재가공 금지 조항) 확인
- 쇼노트에 원문 링크를 남겨 출처 명시

## 리스크와 대응
- 요약 오류(숫자·이름) → 대본 생성 후 원문 대조 검증 단계, 불확실한 수치는 읽지 않음
- TTS 발음 오류(영문 약어, 고유명사) → 발음 사전 파일로 치환
- 소스 RSS 변경·중단 → 수집 실패 3일 연속이면 알림
