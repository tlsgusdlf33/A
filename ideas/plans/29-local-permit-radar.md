# 29. 관심 지역 인허가·개발 고시 반경 알림

## 최종 목표
- **관심 지점 반경 안의 일정 규모 이상 건축 인허가·정비사업 변화를 놓치는 일 0건** (분기마다 수동 검색과 대조해 검증)
- 공공데이터에 공개된 뒤 **7일 안에** 알림 (데이터 공개 주기에 따라 조정)
- 반경 밖 오탐 0건, 알림 1건 확인 시간 1분 이하

## MVP 범위
- 관심 지점 3곳 (집, 관심 단지 2곳), 반경 1km
- 건축 인허가 정보부터 시작 → 정비사업·도시계획 고시는 거주 지역에서 쓸 수 있는 소스를 확인 후 추가
- 텔레그램 알림 + 월간 지도 리포트

## 기술 구조
- 데이터:
  - 국토교통부 건축 인허가 정보 (공공데이터포털): 대지 위치, 주용도, 연면적, 층수, 허가·착공·사용승인일
  - 정비사업·도시계획 고시: 지자체별 공개 데이터(예: 서울시 정비사업 정보), 토지이음 고시 정보 등 — **API 제공 여부를 지역별로 확인**, API가 없으면 공식 RSS·공개 데이터만 사용
- 지역 범위: 관심 지점 → 해당 법정동과 인접 법정동 코드 목록 → 그 범위만 조회
- 좌표 변환: 국토정보플랫폼(브이월드) 지오코딩 API 또는 지도 서비스 로컬 API
- 필터·중요도: 반경 거리 계산 → 용도(대규모 공동주택, 판매·업무시설, 학교, 기피 시설 등)와 규모(연면적·층수)로 중요도 점수
- 알림: 텔레그램 (요약 + 단계 표시 + 지도 링크)
- 월간 리포트: 정적 HTML 지도 (오픈스트리트맵 타일, 출처 표시)
- 1번(공공데이터 사이트)과 데이터·코드 공유 가능 (실거래가 변화를 같은 지도에 표시)
- 저장: SQLite, 비용: 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 확인 | 건축 인허가 API 활용 신청, 조회 조건(법정동·기간)·필드·갱신 주기 확인. 거주 지역의 정비사업·고시 데이터 소스 조사 | 지역별 사용 가능 소스 표 |
| 1. 관심 지점 설정 | 지점 주소 → 좌표, 반경, 조회할 법정동 목록 자동 계산 | 설정 파일 완성 |
| 2. 수집기 | 매일(또는 데이터 갱신 주기에 맞춰) 해당 법정동 인허가 수집, 중복·변경(허가 → 착공 → 사용승인) 추적 | 30일치 백필 성공 |
| 3. 좌표·반경 필터 | 대지 위치 지오코딩 → 거리 계산 → 반경 안만 남김, 변환 실패 건은 "확인 필요" | 반경 밖 오탐 0건 |
| 4. 중요도 점수 | 용도·규모·층수 기준 점수, 기피 시설·일조 영향(고층) 표시 | 상위 알림이 직접 판단과 일치 |
| 5. 알림 | "무엇이(용도·규모) 어디에(거리·방향) 어느 단계" + 지도 링크 | 2주 실사용 |
| 6. 정비사업·고시 추가 | 0단계에서 확인한 지역 소스 연결, 구역 지정·조합 설립·사업시행인가 등 단계 변화 감지 | 소스 1개 이상 추가 |
| 7. 월간 지도 리포트 | 반경 내 변화 지도 + 목록, (선택) 실거래가 추이 함께 | 매달 1일 자동 생성 |
| 8. 검증·확장 | 분기마다 수동 검색과 대조해 누락 확인, 관심 지점 추가 | 누락 0건 유지 |

## 법·정책 주의사항
- 공공데이터별 이용 조건과 출처 표시 준수, 공식 API·공개 데이터만 사용 (지자체 게시판 무단 수집 금지)
- 인허가는 개발 확정이 아님: 허가 후 착공 지연·취소도 흔하므로 단계를 함께 표시
- 개인 판단 참고용: 부동산 거래 결정은 공식 문서·현장 확인 후

## 리스크와 대응
- 주소 형식 불일치로 지오코딩 실패 → 지번·도로명 둘 다 시도, 실패 건은 법정동 단위로라도 알림
- 데이터 공개 지연 → 알림에 "데이터 기준일" 표시
- 지역마다 고시 데이터 형식이 다름 → 소스별 파서를 분리해 하나씩 추가
