# 매일 아침 아이디어

매일 아침 삶의 질을 높일 아이디어 3가지를 제안하는 루틴의 작업 공간입니다.

## 규칙
- 매일 3가지, `history.md`의 기존 항목과 겹치지 않을 것 (제목뿐 아니라 핵심 메커니즘·수익 구조까지)
- `탈락` 항목과 비슷한 방향은 피할 것
- 아이디어마다 개념, 자동화 구조, 수익 또는 효과, 현실적인 기대치, 첫 단계를 짧게 적을 것
- 제안한 뒤 `history.md`에 `제안` 상태로 추가

## 채택 경향 (2026-10-06 기준)
- **채택:** 프로그램으로 만들어 자동으로 돌아가는 것, 수익(광고·제휴·판매·구독·라이선스)이나 돈 절약으로 이어지는 것
  - 1, 4, 6, 7, 8, 10, 12, 13, 16, 17, 18
- **탈락:** 본인의 습관·행동에 의존하는 루틴, 관계·건강·학습 습관형
  - 3, 5, 9, 11, 15
- 따라서 새 아이디어는 "Claude Code로 개발해서 자동으로 돌아가는 프로그램"을 중심으로 낼 것. 분야는 섞되 습관형 루틴은 지양

## 채택 항목 상세 계획 (`plans/`)
- `채택` 항목마다 `plans/NN-이름.md`에 **최종 목표**와 **자세한 절차**를 작성
- 다른 Claude Code 세션에 그대로 넘겨 개발을 시작할 수 있는 수준으로 작성:
  최종 목표(측정 가능한 지표), MVP 범위, 기술 스택·구조, 단계별 절차(각 단계의 완료 기준), 필요한 계정·API·비용, 법·정책 주의사항, 리스크
- 매일 루틴에서 계획 문서가 아직 없는 `채택` 항목을 **번호 순으로 하루 최대 3개**씩 작성하고, 채팅에 최종 목표와 절차 요약을 함께 제시
- 새로 `채택`된 항목은 다음 루틴에서 우선 작성
- 계획을 쓰면 `history.md` 메모 칸에 `plans/NN-이름.md` 링크 추가

## 상태 바꾸기
채팅에서 "N번 탈락", "N번 채택"처럼 말하면 `history.md`의 상태가 업데이트됩니다.
상태: `제안` · `채택` · `보완반영` · `애매` · `탈락`
